## The whole integration

<DepositSnippet />

Install it with `npm i uniport-sdk`, then follow the [quickstart](/docs/quickstart). It takes about three minutes.

## How it’s built

Uniport routes payments through NEAR Intents (the 1Click API). The SDK calls Uniport’s hosted backend, which returns quotes, deposit addresses and payment status. Your client never holds an API key.
