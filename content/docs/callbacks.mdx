## Usage

<Code
  file="DepositAction.tsx"
  code={`import { UniportButton } from "uniport-sdk";

export function DepositAction() {
  return (
    <UniportButton
      appId="app_..."
      recipient="0x..."
      destinationToken="optimismUSDC"
      label="Deposit"
      onSuccess={(result) => console.log(result.depositAddress)}
      onError={(error) => console.error(error.message)}
      onOpenChange={(open) => console.log(open)}
    />
  );
}`}
/>

## onSuccess

Called when the payment completes. It receives:

<DocTable
  head={["Field", "What it is"]}
  rows={[
    [<M>txHash</M>, "The first transaction hash on the destination chain, or an empty string if none was reported."],
    [<M>amount</M>, "The quoted amount delivered, in the destination token’s smallest units."],
    [<M>depositAddress</M>, "The payment’s deposit address. Send this to your server to confirm the payment."],
    [<M>depositMemo</M>, "The deposit memo, on chains that use one."],
    [<M>correlationId</M>, "A reference for the quote, useful when asking for support."],
  ]}
/>

`onSuccess` runs in the payer’s browser, so treat it as a hint and not as proof. Before you ship goods or grant access, [confirm the payment on your server](/docs/confirm-payment).

## onError

Called when the payment fails. It receives an `Error`. Failures from Uniport’s backend arrive as a `UniportError` with a `code`; see [Errors](/docs/errors).

## onOpenChange

Called with `true` when the modal opens and `false` when it closes.
